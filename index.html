Three I would show first

TubeYou

PHP 8, MariaDB, vanilla JS, Docker · repository

A video platform with the parts that are actually hard: upload and streaming over HTTP range requests, subscriptions, a comment system with replies, pinning and editing, email verification, full text search, and a scored feed.

Built with no framework at all, MVC written by hand. It is difficult to know what a framework does for you until you spend a month doing it yourself.

The hosted demo is offline. The code and setup live in the repository.

WebLeads

Python, SQLite · private repository

A pipeline for finding web design work with local businesses: find candidates, audit their existing site technically, rank who is worth the effort, collect a brief, build a prototype, prepare an approach. Ranking matters most, because a prototype is the most expensive decision in the chain and most leads do not justify one.

There is no SMTP code in it, deliberately, and adding any is forbidden. Polish telecoms law and GDPR make automated cold outreach a legal problem rather than a technical one, so the system drafts and a human sends every message by hand. A pipeline that cannot send is the entire point.

dropgate

Python, standard library only · repository

Drop a file, get a tokenised link, send it to someone. One Python file, zero dependencies, and it runs portable off a USB stick. Tokens are 128 bit capabilities, comparisons are constant time, and path traversal is closed by reducing every requested name to its basename against a per share allowlist.

The public server and the admin panel are separate processes, and only the public one is ever attached to the tunnel. The panel is not protected by a setting I could get wrong. It has no route to the internet at all.

Where I learn the things code cannot teach

One Ubuntu machine running roughly 25 containers: self hosted Git, storage, media, dashboards, monitoring. Nothing is port forwarded. Everything reaches the internet through a tunnel and sits behind SSO, and administration runs over a private mesh.

You can check that claim without my help. Pick any service subdomain on this domain and you will land on a login screen rather than inside the service.

It went down once in a way I could not explain, and the fix erased the evidence before I could read it. So now the machine records its own configuration on a schedule, and the next outage will have a before.
