Three I care about most

TubeYou

PHP 8 · MariaDB · vanilla JS · Docker · repository

A video platform with the parts that are actually hard: upload and streaming with HTTP range requests, subscriptions, a comment system with replies, likes, pinning and editing, email verification and password reset, full-text search, and a scored feed. Built on PHP 8 with no framework at all, an MVC structure written by hand, because the point was to find out what a framework does for you by not having one.

The hosted demo is currently offline; the code and setup are in the repository.

WebLeads

Python · SQLite · private repository

A pipeline for finding web design work with local businesses: find candidates, audit their existing site technically, rank who is actually worth the effort, collect a brief, build a prototype, prepare an approach. The ranking step matters most, because building a prototype is the single most expensive decision in the chain and most leads do not justify one.

The design constraint that shaped everything: there is no SMTP code in it, deliberately, and adding any is forbidden. Polish telecoms law and GDPR make automated cold outreach a legal problem rather than a technical one, so the system drafts and a human reads and sends every single message by hand. A pipeline that cannot send is the entire point.

dropgate

Python, standard library only · repository

Drop a file, get a tokenised link, send it to someone. One Python file, zero dependencies, and it runs portable off a USB stick with an embeddable interpreter and cloudflared next to it.

It runs two separate servers on purpose: a public one that serves nothing but /d/<token>, and an admin panel bound to 127.0.0.1. Only the public port is ever attached to the tunnel, so the panel cannot be exposed to the internet even by a mistake in configuration. The guarantee is structural rather than a checkbox. Tokens are 128-bit capabilities, comparisons are constant-time, path traversal is closed by reducing every requested name to its basename and checking it against a per-share allowlist, and shares can expire, cap their download count, or burn after the first read.

Other work

regexplode

A regex engine written from zero with two matchers, backtracking and a Pike VM, running side by side so you can watch one fall off a cliff on input the other handles flat. Validated differentially against the browser's own engine across 35,148 patterns and 46 inputs: 1.6 million comparisons, zero divergences.

particle-life

A few particle types and a matrix of attraction and repulsion between each pair. The rules are trivial and purely local, but iterate them and cells, swarms and something resembling predation fall out on their own. Nothing about those shapes is programmed anywhere.

physarum

Slime mould transport networks on the GPU, running Jones' 2010 agent model with four render passes per step in WebGL2. Thousands of agents leaving and following a trail map until the whole thing solves a maze it was never told about.

Pontifex

A reactive engine for infrastructure tickets: identify the client, match the report against markdown runbooks, diagnose, then propose a fix that an administrator has to approve before anything executes, behind a hard rail that survives .. and symlinks. Tamper-evident hash-chained audit log; prompt injection and destructive instructions get quarantined rather than run.

Working engine prototype — input channels and remote execution are still mocked.

The homelab

One machine, an HP EliteDesk running Ubuntu, carrying roughly 25 Docker containers: self-hosted Git, file storage, media, dashboards, monitoring, and a scheduled updater that only speaks up when something actually changed.

Nothing is port-forwarded. Every service reaches the internet through a Cloudflare tunnel and sits behind SSO, administration goes over a private Tailscale mesh, and availability is watched from inside. The claim is checkable without my help: pick any service subdomain on this domain and you will be bounced to a login screen rather than into the service.

It has also taught me more about failure than any of the code, including an outage where the fix erased the evidence, which is why I now record configuration state before things break.
