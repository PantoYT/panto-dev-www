PKOTracker

PKOTracker is a personal tool that reads my own bank account so I can track my own finances. It has no other users and no sign-up. If you have arrived at this page from a bank consent screen, that consent is mine, given by me, for my own account.

It reads data through Enable Banking, a licensed account information service provider, under the PSD2 access rules. The application is registered in Enable Banking's restricted mode, which can only ever read accounts that have been explicitly linked to it.

What is processed

  • account identifiers such as IBAN, account name and currency,
  • account balances,
  • transaction history: dates, amounts, currency, counterparty names and payment descriptions.

Where it is stored

In a single SQLite file on my own computer. It is not uploaded anywhere, not sent to any third party, not used for analytics or profiling, not sold, and not shared. There is no server component and no cloud database.

Access is read-only

The access granted is account information only. The application cannot initiate a payment, transfer, or any other movement of funds. That capability is not merely disabled: it is not part of the access that was granted.

How long it is kept

Until I delete the local database. The bank consent itself expires after at most 180 days under PSD2 and has to be renewed deliberately.

Withdrawing consent

Consent can be revoked at any time in the bank's own third-party access settings, or by deleting the session through the Enable Banking API. Once revoked, no further data can be fetched.

Other people's data

Transaction records unavoidably contain counterparty names. That data stays on my machine, is never published, and is not used for any purpose beyond reading my own account history.

Your rights

If you believe I hold data about you and want to ask about it, write to kontakt@panto-dev.com. Note that processing carried out by a natural person purely for personal purposes falls outside the scope of the GDPR, but I will answer regardless.
