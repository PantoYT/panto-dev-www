Short_Forge and TikTok

Short_Forge is a quality-review tool for turning long-form footage into a small number of creator-approved short-video drafts. Its TikTok integration is available from the access-controlled creator workspace. It uses TikTok Login Kit only after the creator chooses to connect their own account.

Data requested from TikTok

Short_Forge requests the user.info.basic and video.list scopes. They allow it to receive the connected account's TikTok open ID, display name and avatar URL, and metadata for that account's public videos such as title, description, duration, cover URL, embed link and creation time. It does not request engagement counts, private videos, messages, contacts or posting permission, and it does not download the listed TikTok videos.

Why and where it is processed

The data is used only to show the connected creator their profile and recent public videos inside the Short_Forge integration workspace. Access and refresh tokens are stored server-side in a local application file and are never exposed to browser JavaScript. Profile data may be cached alongside that token so the workspace can show connection status. This data is not sold, used for advertising, combined with data from other projects or used to train a model.

Cookies and retention

The public Short_Forge information pages use no analytics or advertising cookies. The protected integration workspace sets one first-party, secure, HttpOnly session cookie named shortforge_review. It authenticates the current review session and carries no TikTok access token. The server forgets web sessions when the application restarts. TikTok tokens and cached profile data are kept until the creator disconnects, the authorization expires, or the local application data is deleted.

Disconnecting and deletion

The creator can use Disconnect account in Short_Forge at any time. The application asks TikTok to revoke the token and then removes its local token, cached profile and pending OAuth state. Authorization can also be removed in TikTok's own security settings. To ask whether any Short_Forge data remains or request deletion, contact contact@panto-dev.com.

Processors

TikTok processes login, consent and TikTok account data under its own privacy terms. Cloudflare carries ordinary network data while providing DNS, TLS and traffic delivery for the public site. No separate analytics provider is used.

If you believe I hold data about you and want to ask about it, write to contact@panto-dev.com. Note that processing carried out by a natural person purely for personal purposes falls outside the scope of the GDPR, but I will answer regardless.
